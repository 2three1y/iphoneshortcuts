How the iOS 27 prompts work

iOS 27 added Describe a Shortcut to the Shortcuts app. You type or dictate what you want, and Apple Intelligence builds the shortcut, automation included. It needs Apple Intelligence turned on, which works on iPhone 15 Pro, all iPhone 16 models, and newer.

  1. On this page, fill in the boxes above a prompt if it has any. Then double-tap its Copy button. You'll hear “Copied”.
  2. Open Shortcuts and double-tap Add (the plus) at the bottom.
  3. A box asks what you want your shortcut to do. Double-tap and hold in the box, then double-tap Paste.
  4. Double-tap the button next to the box to create it. Shortcuts builds it and reads you a short summary of what it made.
  5. Check it can run by itself: double-tap Edit, then the Info button (an i in a circle), then Privacy, and turn on Allow Running When Locked.
  6. Test it, using the test steps in that shortcut's section.

If the plus opens a blank editor instead of the box, go to Settings, then Apps, then Shortcuts, and switch it away from Editor. AI can get a detail wrong, so always test. The by-hand steps are there if it does.

Sources: Apple: New in iOS 27 Shortcuts, Apple: Add automations to Shortcuts, CNET: the Describe a Shortcut feature.

Shortcut 1: If my iPhone is stolen

Someone you trust texts your iPhone a secret word. Your iPhone texts them back where it is, all by itself. No Face ID needed.

Idea from All By Allan: watch his original TikTok. This is the simplest version of it.

Prompt for iOS 27

Fill in the two boxes first, and the prompt updates. What you type stays on this page. Nothing is saved or sent.

The prompt

Create a shortcut named “Where Is My iPhone” with an automation that runs when I get a message from [trusted person’s name] that contains the word “[secret word]”. Set the automation to run immediately, without asking first and without a notification, and allow it to run when my iPhone is locked. The actions, in order: 1. Get Current Location. 2. Send Message: send the current location to [trusted person’s name], with Show When Run turned off, so it sends without anyone tapping Send.

Before you start

  • Pick one person you trust completely, like a parent. They need to be in your Contacts.
  • Pick a secret word. Make one up, so it never shows up in normal texts. Do not use the word “location”.
  • Tell that person the word privately, in person or on a call.
  • Open the Shortcuts app. It comes with every iPhone. If it's missing, get it free from the App Store.

Button names below are what VoiceOver reads on recent iOS versions. Apple renames things now and then, so if a name is a little different, look for the closest match.

Build it by hand: the 6 steps

These steps were written before iOS 27. On iOS 27, automations live inside a shortcut: double-tap Add (the plus), then Edit, then Automation, and choose Message. Then add the actions from steps 4 and 5. The prompt above does all of this for you.

  1. Start a new automation

    1. In Shortcuts, double-tap the Automation tab at the bottom.
    2. Double-tap New Automation. If you already have automations, it's the Add button (the plus) at the top right.
    3. Swipe right until you hear Message, then double-tap it. It's in the Communication group. You can also type Message in the search field at the top.

  2. Choose who and the secret word

    1. Next to Sender, double-tap Choose. Type your trusted person's name, double-tap them, then double-tap Done.
    2. Next to Message Contains, double-tap Choose. Type your secret word, then double-tap Done.

  3. Make it run by itself

    1. Double-tap Run Immediately. Not “Run After Confirmation”, which would wait for you to tap.
    2. If you hear Notify When Run, turn it off, so a thief doesn't see a pop-up.
    3. Double-tap Next at the top right.
    4. Double-tap New Blank Automation. On some iOS versions it's called Create New Shortcut.

  4. Add “Get Current Location”

    1. Find the search field. It's at the bottom of the screen, labeled something like Search for apps and actions. If you hear Add Action first, double-tap that.
    2. Type Get Current Location.
    3. Double-tap the result with that exact name.

  5. Add “Send Message”

    1. Use the search field again. Type Send Message, then double-tap the result.
    2. The action reads like “Send Current Location to Recipients”. If it says Message instead of Current Location, double-tap Message and choose Current Location.
    3. Double-tap Recipients. Type the same trusted person's name and double-tap them.
    4. If you hear Show More on this action, double-tap it and turn off Show Compose Sheet (or Show When Run), so the text sends without anyone tapping Send.
    5. Double-tap Done at the top right. That's it, it's saved.

  6. Test it

    1. Ask your trusted person to text you the secret word.
    2. Within a few seconds, they should get a text back from your phone with your location.
    3. If nothing comes, open the automation and check the sender, the word's spelling, and that Run Immediately is on.

Secret word ideas

Made-up words work best, because nobody types them by accident. Pick one, or invent your own:

  • zorbleflap
  • pickletornado
  • toastermoon
  • quokkasaurus
  • wobblecrumpet
  • kazoocomet

Avoid real words like “location”, “where”, “phone” or “help”. They come up in normal texts, and the automation would send your location each time.

Also turn on Find My

This Shortcut adds to Find My. It doesn't replace it. Turn Find My on too:

  1. Open Settings.
  2. Double-tap your name at the top.
  3. Double-tap Find My, then Find My iPhone.
  4. Turn on Find My iPhone.
  5. Turn on Find My network, which can find it even when it's offline.
  6. Turn on Send Last Location, which sends its spot when the battery is almost dead.

Apple's Stolen Device Protection needs Face ID or Touch ID, so it may not be an option for you. This Shortcut plus Find My is a good alternative.

Honest limits

  • Airplane Mode or powering off stops it. The phone needs signal to get the text and reply. The Airplane Mode shortcut below helps with that.
  • It's only as private as your word. Your trusted person can get your location any time they text it. Pick someone you fully trust, and a word that never comes up in normal texts.
  • Keep the word secret. Share it only privately with that one person.
  • Location may be rough indoors. It's usually close, but not always exact.
  • Stolen phone? Don't chase anyone. Give the location to a parent or the police.

Extras (optional)

These add more, but they're fiddlier with VoiceOver. The 6 steps above already work on their own.

Send a Google Maps link instead

This is what the original video does. Add these before Send Message, then change Send Message to send the Text.

  1. After Get Current Location, search for the Text action and add it.
  2. In the text box, type https://www.google.com/maps?q=
  3. Insert the Current Location variable right after the equals sign. It's in the bar above the keyboard, or under Select Variable.
  4. Double-tap that inserted variable and choose Latitude.
  5. Type a comma, with no spaces.
  6. Insert Current Location again, double-tap it, and choose Longitude.
  7. In Send Message, double-tap the message part and choose Text.

The finished text looks like: https://www.google.com/maps?q=LATITUDE,LONGITUDE, with your real numbers in place of the capital words.

Send photos from both cameras
  1. At the end of the automation, search for Take Photo and add it.
  2. Set the camera to Back. Double-tap Show More and turn off Show Camera Preview.
  3. Add another Send Message. Set the message to Photo and the recipient to your trusted person.
  4. Do steps 1 to 3 again with the camera set to Front.
  5. Double-tap Done.

Heads up: iPhones often block the camera while locked, so photos may not send from a locked phone. The location text still works either way.

Shortcut 2: Stop thieves turning on Airplane Mode

Thieves often turn on Airplane Mode so Find My can't track the phone. With this, Airplane Mode asks for a code. Get it wrong, and your iPhone turns Airplane Mode back off, takes a selfie, texts it and its location to someone you trust, and locks itself.

From Tech in Her Step: watch her TikTok. One change from the video: we turn Airplane Mode back off before texting, because texts can't go out while it's on.

Prompt for iOS 27

Fill in the two boxes first, and the prompt updates. What you type stays on this page. Nothing is saved or sent.

The prompt

Create a shortcut named “Airplane Mode Lock” with an automation that runs when Airplane Mode is turned on. Set the automation to run immediately, without asking first, and allow it to run when my iPhone is locked. The actions, in order: 1. Ask for Input, input type Number, with the prompt “Enter 4-digit code”. 2. If the provided input is not [your 4-digit code], then do all of these, in this order: turn Airplane Mode off; Take Photo with the front camera, with Show Camera Preview turned off; Get Current Location; Send Message with the photo to [trusted person’s name]; Send Message with the current location to [trusted person’s name]; Lock Screen. 3. Turn off Show When Run on both Send Message actions, so they send by themselves. 4. If the code is right, do nothing else and leave Airplane Mode on.

Build it by hand

New actions always land at the bottom. Steps 6 to 11 must sit inside the If, above Otherwise or End If. Moving actions with VoiceOver is fiddly, which is why the prompt is easier.

  1. Start the shortcut

    1. In Shortcuts, double-tap Add (the plus). If you get the describe box, double-tap Edit to build by hand.
    2. Double-tap the name at the top and rename it Airplane Mode Lock.

  2. Add the Airplane Mode trigger

    1. In the search field, type Automation and double-tap it.
    2. Choose Airplane Mode, set to Is Turned On, and choose Run Immediately.

  3. Ask for the code

    1. Search Ask for Input and add it.
    2. Set the input type to Number, and the prompt to Enter 4-digit code.

  4. Check the code

    1. Search If and add it. It reads “If Provided Input”.
    2. Change is to is not. Then double-tap the empty value and type your code.

  5. Turn Airplane Mode back off

    1. Search Set Airplane Mode, add it, and set it to Off. Move it inside the If.

  6. Take a selfie

    1. Search Take Photo and add it. Set the camera to Front. Double-tap Show More and turn off Show Camera Preview. Move it inside the If.

  7. Get the location

    1. Search Get Current Location, add it, and move it inside the If.

  8. Text the photo

    1. Search Send Message and add it. Set the message to Photo and the recipient to your trusted person. Under Show More, turn off Show When Run. Move it inside the If.

  9. Text the location

    1. Add another Send Message. Set the message to Current Location, the same person, and turn off Show When Run. Move it inside the If.

  10. Lock the screen

    1. Search Lock Screen, add it, and move it inside the If, last.

  11. Let it run by itself

    1. Double-tap the Info button (an i in a circle), then Privacy. Turn on everything there, like Allow Running When Locked, and choose Always Allow if asked.

Test it

  1. Tell your trusted person you're testing.
  2. Turn on Airplane Mode in Control Center and type a wrong code.
  3. Airplane Mode should turn off, your screen should lock, and they should get a selfie and your location.
  4. Try again with the right code. Nothing should happen, and Airplane Mode stays on.

Honest limits

  • You'll get the code box too. Any time you turn on Airplane Mode, type your code.
  • Closing the box may stop it. If someone dismisses the code box instead of typing, the shortcut can stop with Airplane Mode still on.
  • Turning the phone off isn't blocked. Keep Find My on, with Find My network, as in Shortcut 1.
  • Block Control Center on the Lock Screen. Go to Settings, then Face ID and Passcode, then under Allow Access When Locked, turn off Control Center. Then a thief can't reach Airplane Mode without unlocking.
  • The selfie may not send from a locked phone. iPhones often block the camera while locked. The location text still works.
  • Stolen phone? Don't chase anyone. Give the location to a parent or the police.
