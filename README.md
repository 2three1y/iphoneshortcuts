# iphoneshortcuts

iPhone Shortcuts: a growing collection of iPhone Shortcuts and automations, written step by step for VoiceOver. Each one has a copy-paste prompt for iOS 27's Describe a Shortcut, plus steps to build it by hand.

Live: https://2three1y.github.io/iphoneshortcuts/

1. If my iPhone is stolen: someone you trust texts your iPhone a secret word, and it texts them back where it is. Idea from All By Allan: https://www.tiktok.com/@all.by.allan/video/7702242061294062861
2. Stop thieves turning on Airplane Mode: Airplane Mode asks for a code, and a wrong code sends a selfie and the location to someone you trust. From Tech in Her Step: https://www.tiktok.com/@techinherstep/video/7697410415067712798

Plain HTML and CSS, plus a small script for the copy buttons. Co-written with Tab. MIT licensed.
