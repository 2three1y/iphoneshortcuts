# stolenphoneshortcut

A simple, VoiceOver-first guide to an iPhone Shortcut automation: someone you trust texts your iPhone a secret word, and it texts them back where it is. No Face ID needed.

Live: https://2three1y.github.io/stolenphoneshortcut/

Idea from All By Allan: https://www.tiktok.com/@all.by.allan/video/7702242061294062861

Plain HTML and CSS, no scripts. Co-written with Tab. MIT licensed.
